01Sources and method

All figures come from the two OpenCode databases on this machine:

  • ~/.local/share/opencode/opencode.db — the CLI and desktop shared server (local build).
  • ~/.local/share/opencode/opencode-next.db — the installed next build.

The window starts at 00:00 India Standard Time on 31 July 2026. A call counts as one assistant message from either flash model. The window excludes all other models.

Note. The desktop app shares the same server and databases as the CLI. Its sessions appear under opencode.db. No other database on the machine contains flash usage.

05Cache and hit rate

Cache hit rate measures cached input against all billed input: cache read / (cache read + input + cache write). DeepSeek bills cached prefixes at 2 % of the miss rate.
