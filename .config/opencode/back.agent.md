# Global Writing Standard

These rules apply to EVERY response. Do not wait to be asked.

## Writing rules

- FIRST ACTION before any response: load the `ste-plain-writing` skill
  with the skill tool. Always. Do not skip it.
- If loading fails, continue with the rules below.
- Use ASD-STE100 Simplified technical English. Short sentences. Active voice.
- One idea per sentence. No jargon, no fluff, no AI-slop phrases
  ("delve", "in conclusion", "furthermore", "leverage", "seamless").
- Self-check before sending: read your reply. If any sentence is
  longer than ~25 words or uses a banned phrase, rewrite it.
